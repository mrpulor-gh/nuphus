一个把颜色藏起来的界面

这套界面本身几乎是纯单色，彩色只存在于被展示的组件里。大留白、浅灰大圆角容器、黑色胶囊主按钮，构成了一套安静但不空的画廊式视觉系统。

桌面 1440 / 1024 / 768 移动 390 Light + Dark
00

设计 DNA

不是“极简风格”四个字，而是三条明确取舍：界面退后、内容上前、动作只有一个。

01 / chrome

安静的外壳

导航、标签、边框全部低对比。没有品牌色铺底，也没有装饰性渐变。彩色只留给作品本身。

02 / surface

浅灰大圆角

卡片和面板统一 28px 圆角，用 6% 墨色洗底代替边框和阴影。层级靠底色深浅，而不是线框。

03 / action

黑色胶囊

主操作永远是黑色药丸，白字。次要操作退回透明加 1px 内描边。全站只允许一个视觉强动作。

01

布局与节奏

桌面 20px 边距，移动 14px。没有 max-width 居中容器，内容直接撑满视口。网格是瀑布流列，不是等高卡片矩阵。

02

颜色

核心是一个 6 级墨色梯度加一层 6% 透明洗底。主色不是某个蓝或紫，而是“墨”。彩色只出现在组件预览、状态点和极少数的信号色里。

两条硬规则

第一，界面 chrome 不使用品牌色，彩色只属于内容。第二，层级优先用 wash 透明洗底和圆角表达，不堆边框、阴影、描边三件套。唯一允许的渐变是顶部促销条的 MCP 文字和组件内部的视觉素材。

Dark theme

--bg #000，--surface #0f0f0f，--surface-2 #181818，--ink #fff。深色下把 wash 提到 9%，成功色提亮到 #34d17a，避免在纯黑上发闷。

纯黑是最强的对比层

深色区块不靠边框区分，直接换成纯黑底，四周留 20px 白边。白色胶囊按钮在纯黑上就是唯一焦点。

04

组件语言

按钮、搜索、分段控件、卡片、详情面板，五类组件就构成了整套界面。共同点：大圆角、无重阴影、状态变化只改底色和透明度。

05

动效与响应式

动效是短促、向外的弹簧感：进场升 8px 后落定，按下轻微缩小。没有弹跳、没有旋转、没有超过 600ms 的界面动效。

06

翻译到 Nuphus

这套语言是“Explore / 画廊”型界面，Nuphus 是“Operate / 日常工具”型界面。学它的 token 和控件语言，不要照搬它的落地页构图。

直接可用的

  • 把桌面外壳统一成 ink 六级灰 + wash 洗底，减少现有边框数量。
  • 主按钮统一黑色胶囊；次级按钮透明加 1px 内描边；危险操作才用红。
  • 侧栏、气泡、工具面板用 20 / 24 / 28px 圆角；阴影只留给浮层和弹窗。
  • 标题用 500 + 负字距；正文 13 / 1.5；说明文字用 ink-3/4，不要用纯灰。
  • 工具调用沿用“名称 + 洗底参数代码块 + 状态图标 + 括号耗时”，与移动端执行过程一致。

需要克制的

  • 不要把首页那种巨大 hero 和大留白搬进聊天主界面，日常使用要密度。
  • 卡片网格适合画廊，不适合消息流；消息流仍用线性时间轴。
  • 彩色只用于状态和工具结果，界面本身保持单色，避免聊天记录变成调色盘。
  • 动效只保留按压和浮层入场，流式输出区域不要加额外动画，避免与 token 刷新抢注意力。
  • 分段控件适合设置面板，不适合高频主操作；主操作仍然只用黑色胶囊。
一句判断：这套语言最值得学的不是“长得像”，而是它的取舍顺序。先用中性色把界面压平，再把唯一的黑色动作放到最重要的地方，最后才让内容自己带颜色。Nuphus 已经有内容色彩，缺的是这层安静的壳。
