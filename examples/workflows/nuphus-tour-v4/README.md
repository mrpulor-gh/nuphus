# nuphus-tour-v4 — 面板巡览工作流示例

一个桌面自动化工作流示例：通过 `Ctrl+K` 命令面板搜索定位，依次巡览 Nuphus 的 11 个设置面板（打开 → 停留展示 → 关闭），可用于功能演示与录屏。

## 文件

| 文件 | 说明 |
|---|---|
| `workflow.json` | 工作流定义（`run_history` 已清空，可直接导入运行） |
| `params.json` | 固化参数：窗口基线、关闭点公式、搜索词、异常降级 |
| `guide.md` | 使用指南与故障排查 |

## 工作流结构

```
init   初始化
  ├─ desktop_windows_list 取窗口列表
  └─ python 脚本：解析窗口位置/尺寸，预计算每个面板的关闭坐标
tour   面板巡览（for_each 11 个面板）
  ├─ 激活窗口
  ├─ Ctrl+K 打开命令面板
  ├─ 输入搜索词 → Enter
  ├─ 等待面板加载
  ├─ 按面板类型点击关闭点
  └─ 等待关闭动画
```

## 两个关键设计点

**1. 关闭点按界面形态分派**

| 面板 | 关闭坐标 | 原因 |
|---|---|---|
| 模型 | `win.x+34, win.y+37` | 界面全屏铺满窗口，无遮罩层，关闭按钮在窗口左上角 `×` |
| 其余 10 个 | `win.x+50, win.y+win.height-76` | 弹窗形态，点击窗口左下角遮罩区域关闭 |

坐标基于运行时动态获取的窗口位置/尺寸计算，窗口移动或缩放后无需改脚本。

**2. 搜索词去重**

命令面板搜索「工作流」会同时命中「画布（工作流、UI 原型设计与转换工具）」和「工作流（浏览自动化工作流）」，且默认高亮画布。示例改用「**自动化工作流**」，唯一命中工作流列表。

## 已知行为

- `Esc` 无法关闭设置面板，关闭必须走遮罩点或左上角 `×`
- 若上一次运行被中断留下断点，首次执行可能"瞬间完成"（跳过全部步骤、复用旧捕获值），再执行一次即可
