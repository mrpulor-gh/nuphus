# nuphus-tour-v4 使用指南

## 功能
自动巡览 Nuphus 的 11 个面板，通过 Ctrl+K 命令面板以搜索定位方式逐个展示。

## 巡览面板（按顺序）
| # | 面板 | 搜索词 | 关闭点 |
|---|---|---|---|
| 1 | 项目配置 | 项目配置 | 遮罩 |
| 2 | **模型** | 模型 | **左上角 ×** |
| 3 | 主题与语言 | 主题与语言 | 遮罩 |
| 4 | 权限与安全 | 权限与安全 | 遮罩 |
| 5 | 浏览器 | 浏览器 | 遮罩 |
| 6 | 记忆 | 记忆 | 遮罩 |
| 7 | **工作流列表** | **自动化工作流** | 遮罩 |
| 8 | 技能 | 技能 | 遮罩 |
| 9 | 知识库 | 知识库 | 遮罩 |
| 10 | 灵魂 | 灵魂 | 遮罩 |
| 11 | 贪吃蛇 | 贪吃蛇 | 遮罩 |

## 前置条件
- Nuphus 窗口已打开且在桌面可见
- 工作流执行期间不要操作鼠标键盘

## 工作原理
```
init: desktop_windows_list → Python 脚本解析窗口信息 + 预计算每个面板的关闭坐标
                                 ↓
loop (for_each 11 个面板):
  ├─ 激活 Nuphus 窗口
  ├─ Ctrl+K 打开命令面板
  ├─ 输入搜索词 → Enter 进入（搜索框自动聚焦）
  ├─ 等待面板加载（0.6s）
  ├─ 按面板类型点击关闭点
  └─ 等待关闭动画（0.3s）
```

## 关闭点规则（关键）
| 面板类型 | 关闭坐标 | 说明 |
|---|---|---|
| 模型 | `win.x+34, win.y+37` | 界面全屏铺满窗口，无遮罩；关闭按钮在**窗口左上角 ×** |
| 其余 10 个 | `win.x+50, win.y+win.height-76` | 弹窗形态，点击**窗口左下角遮罩区域**关闭 |

脚本中 `mask_*` 为弹窗类坐标，`model_*` 为模型界面坐标，循环构造后单独覆盖 `panels[1]`（索引 1 = 模型）。

## 搜索词规则（关键）
- **工作流 → 用「自动化工作流」**：命令面板搜索「工作流」会命中 2 条——「画布（工作流、UI 原型设计与转换工具）」和「工作流（浏览自动化工作流）」，且**默认高亮画布**，直接 Enter 会误入画布编辑器。
- 「自动化工作流」唯一命中工作流列表，Enter 直达。
- 背景：画布是把「工作流编辑 / UI 原型设计 / 工具」三项合并后的页面，与「工作流列表」是两个不同入口，命名重叠。

## 设计决策
- **搜索定位**而非坐标点击：面板列表位置随窗口大小和滚动状态变化，搜索方式最可靠
- **非 raw 三引号不行**：`{{wins}}` 展开后包含 `\\` JSON 转义，`r'''...'''` raw 字符串保留转义，`json.loads` 正确解析
- **capture 不用 @ 前缀**：新框架 `resolve_vars_str` 的变量名字符检查拒绝 `@`，直接用字母数字名
- **关闭点按界面形态分派**：模型界面全屏后左下角遮罩点会落到界面内容上，必须改用左上角 ×；其余面板保持遮罩点击
- **不用 Esc 关闭**：实测 Esc 无法关闭设置面板（主题与语言实测无效）

## 故障修复
- **面板未打开**：检查 Nuphus 窗口是否在前台，是否有其他弹窗遮挡
- **搜索无结果**：确认搜索词与菜单项名称/描述一致（「工作流」需用「自动化工作流」）
- **误入画布编辑器**：搜索词被改回「工作流」了，改回「自动化工作流」
- **模型界面关不掉**：确认模型界面为全屏形态时 × 仍在左上角；窗口若被移动，坐标随 `win.x/win.y` 自动跟随，无需改脚本
- **其他面板关不掉**：可能窗口高度变化，调整 `mask_y` 偏移（-76 基于 776 高度窗口，当前基线 728）
- **连续失败 3 次**：先手动打开一次 Ctrl+K 确认面板正常，再重试
