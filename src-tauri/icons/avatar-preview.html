Nuphus 虚拟形象体系 — 全状态预览

以身份 ICON 为脸：框 = 颅，双竖 = 目，右下开口 = 气息出入的嘴部。 单色纪律：情绪只用运动表达，永不变色。所有动效遵循动效令牌（见文末）， prefers-reduced-motion 下全部回退为静态姿态（目形本身仍传达状态）。

二、Idle 尺寸阶梯（16 → 96，暗底）

三、状态机映射（Agent 运行时 → 形象状态）

运行时事件形象状态说明
会话空闲idle默认。呼吸 + 每 ~4.6s 眨眼，存在感但不打扰
LLM 调用中（首个 token 前）thinking眼珠左右巡视 + 头部轻摆：「正在想」
工具执行中（desktop/shell/skill）working双竖变均衡器，相位错开：「正在动手」
流式输出中streaming轻快起伏 + 频密眨眼：「正在说」
等待用户确认/输入confirm目睁大 + 注意力脉冲：「在等你」
回合成功完成success跃起一次 + 笑眼弧保持 ~2s 后回落 idle
错误/重试耗尽error目扁平 + 摇头一次后保持：「没办成」，不变红
空闲超时（如 5 分钟）sleep闭目 + 深呼吸，任意交互唤醒回 idle

四、动效令牌（Motion Tokens）

令牌值用途
--nv-blink180ms / 周期 4.6s眨眼：快闭快开，只占周期 6~9%，不催眠
--nv-breathe4.8s ease-in-out，幅度 1.6%呼吸：存在感下限，幅度克制
--nv-work1.1s，双竖相位差 50%执行节律： visibly busy，幅度 45%
--nv-bob1.5s / ±5 单位说话起伏
--nv-jump600ms，squash & stretch成功跃起：先压后弹，卡通物理
--nv-shake900ms，±7° 衰减摇头：一次表达，不持续抱怨
--nv-sway5s / ±2.5°思考头部摆动
